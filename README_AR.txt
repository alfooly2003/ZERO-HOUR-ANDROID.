ZERO HOUR – الحزمة المجمعة

محتويات الحزمة:
- index.html: اللعبة الأساسية، العالمان والمراحل ونظام اللعب الفردي.
- server.js + package.json: سيرفر WebSocket محلي لتبادل أسماء ومواقع اللاعبين عبر Wi‑Fi/Hotspot.
- تشغيل فردي دون اتصال متاح من القائمة.
- شاشة لعب جماعي فيها وضع تعاوني أو مواجهة، واسم اللاعب.
- أسماء اللاعبين الآخرين تظهر فوق شخصياتهم عند اتصالهم.

تشغيل اللعبة الفردية:
1) فك ضغط الحزمة.
2) افتح index.html في Chrome.

تشغيل اللعب الجماعي الحقيقي عبر Hotspot:
يتطلب جهازًا واحدًا يشغّل Node.js كسيرفر (يمكن كمبيوتر أو هاتف Android عليه Termux).
1) اجعل كل الأجهزة على نفس شبكة Wi‑Fi أو Hotspot.
2) على جهاز المضيف ثبّت Node.js و npm.
3) افتح مجلد اللعبة في الطرفية وشغّل:
   npm install
   npm start
4) سيظهر عنوان مثل ws://192.168.x.x:8080 في الطرفية.
5) افتح index.html على كل جهاز، اضغط "لعب جماعي"، اختر "مع بعض" أو "ضد بعض"، اكتب اسمك، وضع عنوان المضيف في خانة العنوان ثم اضغط "انضمام".
6) اترك نافذة السيرفر مفتوحة طوال اللعب.

ملاحظات دقيقة:
- السيرفر ينقل مواقع اللاعبين وأسماءهم وحالتهم الصحية. هذا أساس LAN قابل للتجربة، وليس نظام لعب جماعي نهائيًا متكاملًا.
- اختيار العالم/المستوى لا يتم مزامنته تلقائيًا بين الأجهزة في هذا الإصدار؛ ابدأوا نفس العالم والمرحلة يدويًا.
- وضع "ضد بعض" يحدد نمط الغرفة لكنه لا يحتوي بعد على نظام إصابة/إقصاء لاعب ضد لاعب.
- لا يوجد APK مرفق. هذه حزمة ويب + سيرفر Node.js.
- فتح index.html مباشرة على الهاتف لا ينشئ سيرفر Hotspot؛ يجب تشغيل server.js على جهاز المضيف.
